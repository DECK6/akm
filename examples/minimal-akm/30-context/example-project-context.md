# Example project context

## Context

The example project asks agents to read a directory index before opening detailed project notes. This keeps the first retrieval pass small and makes handoffs easier to audit.

## Constraints

- Do not duplicate long execution logs into indexes.
- Use indexes as entry points, not as replacements for source notes or procedures.
