# 깊이와 포화를 기준으로 하는 발견 대화

목표는 정해진 문항 수를 채우는 것이 아니라 사용자가 알고 있는 것, 당연하게 여긴 것, 아직 언어화하지 못한 판단을 끌어내는 것이다. **한 번에 한 질문만 던지는 규칙을 쓰지 않는다.** 관련된 질문들을 묶어 사용자의 사고를 여러 방향에서 자극한다.

## 한 라운드

1. 답변에서 새로 드러난 대상·용어·판단·긴장·예외를 짧게 정리한다.
2. 아직 파지 않은 가지 중 목적에 중요한 것을 고른다. 사용자의 말을 인용하거나 정확히 요약해 그 말에서 질문을 시작한다.
3. 하나의 쟁점에 대해 여러 갈래로 묻는다. 보통 3~7개의 연결된 질문이 읽기 좋지만 숫자를 목표나 상한으로 삼지 않는다. 사용자가 자유롭게 묶어서 답할 수 있게 한다.
4. 답변을 실제 근거로 기록하고 새로 생긴 가지·남은 가지를 갱신한다. 답하지 않은 항목은 미응답으로 남긴다.
5. 같은 질문을 반복하는 대신 사례·반대 상황·시점·다른 이해관계자·실패·성공 비교로 관점을 바꿔 계속 파고든다.

묶음의 중심 쟁점을 먼저 한 문장으로 짚는다. 관련 질문은 충분히 묻되 독립된 여러 주제를 한 문장 안에 계속 겹치지 않는다. 아직 열지 않은 가지는 탐색 지도에 남겨 다음 묶음으로 이어간다. 이는 한 질문씩 제한하거나 탐색량을 줄이는 규칙이 아니라 사용자가 생각을 이어가기 쉽게 제시하는 방식이다.

## 파고들 축

모든 사용자에게 전부 읽어주는 설문이 아니다. 답에 맞는 축을 골라 질문을 직접 작성한다.

- **목적과 욕구:** 무엇을 알거나 판단하고 싶은가, 왜 지금인가, 답이 있으면 무엇이 달라지는가.
- **구체적 경험:** 최근/기억에 남는 사례, 실제 순서, 선택의 갈림길, 예상과 달랐던 지점.
- **언어와 경계:** 같은 말의 다른 뜻, 비슷하지만 다른 것, 암묵적 분류, 초보자가 오해하는 말.
- **대상과 관계:** 무엇이 무엇에 작용하는가, 방향은 무엇인가, 과정과 구성의 차이, 여러 역할의 교차.
- **판단과 가치:** 잘됐다는 기준, 손해를 감수하는 지점, 서로 충돌하는 기준, 우선순위가 뒤집히는 상황.
- **조건과 반례:** 같은 입력인데 다른 결과, 예외, 설명이 깨진 경험, 보이지 않던 변수.
- **암묵지:** 숙련자가 무의식적으로 확인하는 것, 설명하기 어렵지만 알아보는 차이, 실패를 미리 감지하는 신호.
- **관점과 권한:** 사람마다 다른 판단, 누가 정의하고 결정하는가, 현장과 문서가 다른 지점.
- **시간과 변화:** 예전과 지금의 차이, 바뀐 가정, 잊힌 이유, 앞으로 확인하고 싶은 변화.
- **증거와 빈틈:** 어디서 배웠는가, 직접 경험인가, 기록이 있는가, 믿지만 설명하지 못하는 것은 무엇인가.

## 도메인에 맞추는 법

예를 들어 제빵사의 답에는 반죽 상태를 알아보는 감각·공정 간 조정·배합이 같아도 달라진 결과를, 조경 설계자의 답에는 현장 조건·사용자 동선·계절 변화·설계 의도와 실제 사용의 충돌을 물을 수 있다. 이는 가상 질문 예시이며 사용자나 분야의 사실 데이터가 아니다.

항상 사용자가 실제로 꺼낸 말에서 질문을 만든다. 어떤 분야든 “사례는? 조건은? 예외는?”를 그대로 복사하면 도메인에 맞춘 탐색이 아니다. 초보자는 관찰과 궁금증, 실무자는 선택과 암묵지, 연구자는 정의·설명 경쟁·반증을 출발점으로 삼되 사용자를 숙련도 틀에 가두지 않는다.

## 포화와 종료

사용자가 계속 새로운 내용을 떠올리는 동안 추가 가지를 탐색한다. 정해진 라운드 수, 모델의 문맥 길이, 초기 세 노트의 재료 확보를 완료 기준으로 쓰지 않는다. 긴 대화는 상태를 저장하고 이어간다.

특정 가지에서 막히면 다른 각도나 실제 장면을 제안할 수 있다. 다만 사용자가 전체적으로 “더 생각나는 게 없다”, “이제 정리해 달라”, “여기까지”, “그만”, “건너뛰자”라고 하면 즉시 그 뜻을 따른다. 포화를 더 깊은 질문을 강요할 허가로 해석하지 않는다.

종료 이유는 다음처럼 구분한다.

- `user-saturated`: 사용자가 더 떠오르는 내용이 없다고 표현했다. 표현과 당시 범위를 기록한다.
- `user-directed`: 충분성 판단과 별개로 사용자가 정리/진행/건너뛰기를 요청했다.
- `paused`: 답변 대기 또는 중단. 남은 질문을 저장하며 인터뷰 완료로 만들지 않는다.

한 발화에 포화와 진행 요청이 함께 있으면 명시적인 포화 표현을 기준으로 `user-saturated`를 쓰고, 원래 표현과 다음 행동을 함께 보존한다. 포화 표현 없이 진행을 지시하면 `user-directed`다. 내용 탐색을 마친 상태와 구조/위키를 실제로 작성한 상태는 별개다.

‘질문을 다 했다’가 아니라 **사용자가 어떤 경계까지 생각해 보았고 무엇이 아직 열려 있는가**를 남긴다. 포화는 세계의 모든 지식이 완성되었다는 뜻이 아니다.

## 기록

탐색 지도에는 주제, 사용자의 구체적인 말, 새로 드러난 개념/관계, 미응답·미확인, 다음에 파고들 가지를 남긴다. 실제 진술과 LLM 가설을 분리한다. 정정은 이전 진술과 연결한다. 이 지도가 온톨로지·위키·확장 스킬의 공통 입력이다.
