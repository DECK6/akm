# Progressive disclosure index

## Core definition

A progressive disclosure index is a short directory-level entry point that lets an agent inspect topic summaries before opening every note in a folder.

## Details

In AKM, local indexes can live as `INDEX.local.md` inside high-value layers. In OKF export bundles, they become lowercase `index.md` files for consumers that expect the OKF convention.
