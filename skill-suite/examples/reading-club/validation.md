# 가상 예제 검증 기록

개정 1. 저자가 원문 규칙과 각 설명을 직접 대조한 공개 예제이며 독립 실험이나 실제 사용자 성과가 아니다.

| 질문 | 정상: 기대와 실제 | 반례: 기대와 실제 | 미확인: 기대와 실제 |
|---|---|---|---|
| Q1 | S1 1번에 따라 발표자; N1의 답도 발표자: pass | 진행자가 책을 제안할 책임이라는 결론은 이 자료로 지지되지 않는다. N1도 이 한계를 유지: pass | 2기는 미확인; N1도 미확인으로 답함: pass |
| Q2 | S1 2번에 따라 진행자; N2의 답도 진행자: pass | 기록자가 날짜 결정 책임자라는 결론은 이 자료로 지지되지 않는다. N2도 이 한계를 유지: pass | 2기는 미확인; N2도 미확인으로 답함: pass |
| Q3 | S1 3번에 따라 기록자; N3의 답도 기록자: pass | 발표자가 요약 책임자라는 결론은 이 자료로 지지되지 않는다. N3도 이 한계를 유지: pass | 2기는 미확인; N3도 미확인으로 답함: pass |
