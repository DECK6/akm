# AKM에 통합한 연구와 설계 근거

이 묶음은 공개 AKM 코어, 사용자의 온톨로지·LLM Wiki·지식관리 연구, gstack의 역할 분담과 심층 탐색 방식을 함께 반영한다. 사용자의 개인 지식/사례를 다른 사용자에게 기본 사실로 주입하지 않고 **다른 도메인에서도 적용 가능한 행동 규칙**으로 옮겼다. 이 문서는 근거와 설계의 대응표다. 실제 실행 규칙은 연결한 공통 규약과 각 스킬에 있다.

인지공생은 기존 외부 기억·연결적 사고·확장/분산 인지 논의를 AI-PKM 실천에 재배열한 작업 프레임으로 다룬다. 새 보편 이론이나 실증된 성능 향상이라고 주장하지 않는다. 예전 발표의 넓은 “온톨로지” 표현은 최근 연구의 엄밀한 구분으로 보완한다. 분류 폴더만으로 도메인 온톨로지 구축을 완료했다고 하지 않는다.

## 사용자별로 다시 결정할 것

연구의 사례 도메인·사람 이름·도구·경로는 템플릿 기본값이 아니다. 새 사용자의 반복 질문, 용어, 자료, 판단 기준, 운영 부담을 인터뷰해서 모델과 구조를 정한다. 원문이 없는 지식은 LLM 제안으로 남긴다. 사람의 목적과 책임을 유지한다는 원칙을 모든 가역적 파일 편집에 추가 승인을 요구하는 규칙으로 바꾸지 않는다.

검색 도구, 그래프 DB, OWL/SHACL, 모델 기반 분류, 자동화는 필요한 경우 채택한다. 호스트에 없는 도구를 필수로 요구하지 않는다. 관계만 추가하면 환각이 줄거나 생산성이 높아진다고 보증하지 않는다.

## 범위와 출처 관리

2026-10-09 제작 시 위 핵심 연구 묶음을 직접 읽고 합성했다. 모든 개인 노트·초안·연구 전체를 망라했다고 주장하지 않는다. 정확한 로컬 경로·읽은 범위·해시·선정 기록은 제작 환경의 개발 실행 기록에 보관하며 휴대 가능한 스킬에 개인 볼트 경로를 고정하지 않는다. 추가 연구는 같은 대응표에 의미 있는 변경과 검증을 연결해 편입한다.

공개 코어와 gstack의 URL·버전·라이선스·적용 범위는 [출처](provenance.md)에 있다. 공개 AKM 원본은 배포 자산에 보존하고, 개인 볼트의 내용은 공개 코어로 취급하지 않는다.
