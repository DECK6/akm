# 독서모임의 역할과 책임

가상 예제. 도메인 reading-club, 개정 1.

T-role은 모임 역할, T-task는 할 일이다. R1은 해당 기수에서 한 역할이 수행하는 책임이며 방향은 역할에서 할 일이다. 역방향·대칭·추이는 선언하지 않는다.

| C | 정의 | 종류 |
|---|---|---|
| C1 | 발표자 | T-role |
| C2 | 책 제안 | T-task |
| C3 | 진행자 | T-role |
| C4 | 다음 날짜 결정 | T-task |
| C5 | 기록자 | T-role |
| C6 | 토론 요약 작성 | T-task |

A1: C1 R1 C2, A2: C3 R1 C4, A3: C5 R1 C6. 모두 1기 조건이며 S1의 1–3번 규칙이 각각 지지한다. 주요 주장과 설명의 대응은 knowledge-map.json에 있고 N1–N3으로 읽을 수 있다. 2기의 규칙은 미확인이다.
